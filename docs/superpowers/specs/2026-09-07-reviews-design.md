# Отправка отзывов с сайта — дизайн

Дата: 2026-09-07

## Цель
Добавить возможность отправлять отзыв из мобильной версии сайта в таблицу Notion «Отзывы».

## Триггеры
1. Иконка отзыва в шапке мобильной версии (справа от логотипа, на месте декоративной `.m-header-vector`).
2. Пункт «Отправить отзыв» на странице «Контакты» (переименован из «Написать отзыв в Viber‑Bot», становится кликабельным).

Оба триггера открывают одну и ту же модалку.

## Модалка
Стиль идентичен «Быстрой заявке» (`m-modal#m-modal-shortorder`): `.m-sheet` со скруглением 50px сверху.

Поля и элементы:
- `h3` — «Оставить отзыв».
- Поле «Имя» — `.m-field` (text).
- Поле «Отзыв» — `.m-field-desc` (textarea).
- Переключатель «Анонимно» — по шаблону `.m-option-row` + `.m-toggle`.
- Кнопка «Отправить» — `.m-btn m-btn-primary`.

### Логика «Анонимно»
- Вкл: поле «Имя» блокируется (`disabled`) и очищается; активно только «Отзыв».
- Выкл: поле «Имя» снова активно.
- Отправка: имя уходит пустым, флаг `anonymous=true`.

### После отправки
- Остаёмся на той же странице, где было вызвано окно.
- Показывается состояние «Отправляем» → «Отзыв принят» / ошибка (по образцу существующего `m-modal-sent`).
- Никакой навигации/сброса страницы.

## Backend
Новый endpoint `POST /api/review` (аналог `/api/order`, но без файлов и без телефона).

Данные → Notion:
- `Имя` (title) — имя; при анонимной отправке подставляется «Анонимный отзыв».
- `Отзыв` (rich_text) — текст отзыва.
- `Дата добавления` (date) — текущее время Минск (`minskNow()`).
- `Анонимно` (checkbox) — `true`/`false`.

Переменная окружения `NOTION_REVIEWS_DB` (ID базы) добавляется в:
- `server.js` (чтение + `notionConfigured()`);
- `.env.example`.

Валидация: отзыв обязателен; имя — опционально.
