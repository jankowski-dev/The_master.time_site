# The Master Time

Website for The Master Time — a handyman service in Grodno.

> Skeleton README. Full documentation will be added in Task 16.

## Scripts

| Command            | Description                           |
| ------------------ | ------------------------------------- |
| `npm run dev`      | Start the Astro dev server            |
| `npm run build`    | Build the production app              |
| `npm run start`    | Run the built standalone Node server  |
| `npm run preview`  | Preview the production build          |
| `npm run check`    | Run `astro check` (types + templates) |
| `npm run lint`     | Run ESLint                            |
| `npm run format`   | Format sources with Prettier          |
| `npm run test`     | Run unit tests with Vitest            |
| `npm run test:e2e` | Run end-to-end tests with Playwright  |
